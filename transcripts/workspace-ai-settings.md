The AI Settings panel is where you connect the app to Claude — Anthropic's AI model — so it can generate ad copy for you. Without this, the Generate AI Copy and Build draft features on the New Campaign tab won't be available.

There's a single field here: Claude API Key.

To get an API key, go to console.anthropic.com, sign in or create an account, and generate a key. It'll look something like sk-ant-api03 followed by a long string of characters.

Paste your key into the field and click Save Key.

The key is stored in your operating system's encrypted storage — the same secure location used for your Facebook credentials. It never leaves this device and is never sent anywhere except directly to the Anthropic API when you request AI-generated copy.

Once saved, the field shows a masked placeholder with a Change link if you ever want to update it.

With a key saved, two AI features become available.

Build with AI on the Campaign step — describe your business or goal in a sentence, and the AI generates a full campaign draft including ad set names and structure.

Generate AI Copy on the Creatives step — after selecting tone, hook, and length, click the button and Claude writes primary text, a headline, and description for each creative.

When copy is generated, the AI is sent your tone preferences, the hook style, the length target, and your website URL from the Meta Defaults panel. No personal data or ad account information is included in those requests.

If you're planning to use the app at volume, the AI copy generation pays for itself very quickly. API costs for Claude are typically a fraction of a penny per generation, and a skilled copywriter's time is considerably more expensive. Give it a try and see how the output compares to your existing copy.
