# Default Targeting — Screencast Transcript

**Panel:** Workspace › Default Targeting
**Purpose:** Set the geographic and demographic defaults pre-filled when creating new ad sets.

---

## Intro

The Default Targeting panel is simple but saves a lot of repetitive typing. Whatever you set here gets pre-filled into every new ad set you create. You'll still be able to adjust targeting per ad set in the New Campaign wizard — these are just sensible starting points.

---

## Target Countries

The first field is **Target Countries**.

Enter the countries you want to target by default, using ISO 3166-1 two-letter country codes separated by commas. For example: `GB, US, IE` for the UK, United States, and Ireland.

The app converts what you type to uppercase automatically, so you don't need to worry about capitalisation.

If you only ever advertise in one country, just enter that single code and you'll never need to change it per campaign.

---

## Min Age and Max Age

Below that are the **Min Age** and **Max Age** fields.

These set the age range for your default audience. Facebook's minimum is 13, and the maximum you can set is 65+ (which Meta treats as 65 and above, with no upper limit).

For most direct-to-consumer brands, something like 18–65 is a reasonable default. If your product is specifically for a narrower age group, set that here.

---

## Wrap-up

These defaults are saved to your workspace automatically as you change them. When you go to create a new campaign and move to the Ad Sets step, the countries and age range will already be filled in with these values.
