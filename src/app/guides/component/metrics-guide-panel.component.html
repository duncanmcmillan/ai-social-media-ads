About the Learning Phase

Facebook's delivery system enters a learning phase whenever a new ad or significant change is made. During this phase Meta is optimising who sees the ad — results vary and verdicts are unreliable. An ad exits the learning phase once it has enough data (typically 50 optimisation events).

The Data Floors below define the minimum signals required before the dashboard applies any verdict. If an ad shows "Needs Data", the correct action is usually to let it run, not pause it.
